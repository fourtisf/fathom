Fathom API

An OpenAI-compatible API for private inference. Every request runs inside an attested enclave and nothing is logged.

Quickstart

1. Connect your wallet in the app and top up credits. 2. Create a key under API keys. 3. Point any OpenAI client at our base URL.

curl https://api.fathom.ai/v1/chat/completions \
  -H "Authorization: Bearer fth_live_…" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v3.1","messages":[{"role":"user","content":"Hello"}]}'

Authentication

Send your key in the Authorization: Bearer header. Keys start with fth_live_, are shown once, and don't expire. You can hold up to 10 active keys per wallet and revoke any of them instantly.

Chat completions

POST /v1/chat/completions accepts the same body as OpenAI, including stream, tools and temperature. Two extra fields are available:

  • compare_with: a second model id. The response includes both answers in choices[0] and choices[1].
  • web_search: true lets the model browse through Fathom's egress, never your IP.

Models

GET /v1/models returns available models with live status. Current ids: deepseek-v3.1, qwen3-235b, gpt-oss-120b, llama-3.3-70b.

Rate limits

60 requests per minute per key by default, 300 for Diver tier stakers and above. Failed requests are never charged.

Agent wallets

An agent can own a wallet, sign in with SIWE, and buy its own credits by sending USDG to CreditVault. Use POST /v1/auth/siwe to exchange a signature for a short-lived session key.

Privacy Policy

What we store

  • Your wallet address.

What we never store
