# Noxsea intro video

44s, 1920×1080, 60fps ad built from the website's own design tokens (Geist, glass cards, Sealed Drop mark).

- `ad.html`: every scene on one deterministic timeline. Open `ad.html?play` to preview live, or `ad.html?t=12.5` for a still.
- `music.py`: original synthesized soundtrack (no samples, no licensing). Writes `music.wav`.
- `render-all.sh`: renders frames with headless Chromium in 3 parallel parts, then muxes the music into `noxsea-intro.mp4`.

Copy rules: no token ticker, no profit language, no claims beyond what the product does.
